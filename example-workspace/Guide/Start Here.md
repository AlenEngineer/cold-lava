# Start here

Welcome to the **cold-lava example workspace**: a tiny knowledge base about volcanoes, made to show off
what cold-lava can do. Every note is an ordinary Markdown file, so you can open this folder in
Obsidian too.

Things to try, in order:

1. [[Graph View]]: move around, search, and zoom into a local graph.
2. [[Colour Groups]]: press `g` to colour notes by folder, by tag, or with Obsidian's own groups.
3. [[Whiteboard]]: press `w` and open *Welcome* or *Eruptions Timeline*.
4. [[Agenda and Tasks]]: dated tasks and daily notes, for scripts and status bars.

Good places to start exploring: [[Ring of Fire]], [[Plate Tectonics]] and [[Kīlauea]].

Press `?` at any time for every key.
